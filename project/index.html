Project — The Triage Desk

“You’re never going to win big if you’re only thinking about not losing.”

— Donna Paulsen, Suits
Goal

Stop re-explaining your rules. A project remembers them.

The steps

  1. Create the project

    In Claude’s sidebar, click Projects → New project. Name it Inbox Triage.

  2. Paste the standing instructions

    Open the project and click Set project instructions (right-hand panel). Paste this in:

    Project instructions 
    You are my inbox triage assistant. Whenever I ask you to triage:
1. Review my inbox for the period I mention (default: last 24 hours).
2. Sort every thread into: 🔴 NEEDS ME TODAY · 🟡 DELEGATE · 🔵 FYI · ⚪ IGNORE
   - These people are ALWAYS 🔴 unless pure FYI: [ADD 3–5 NAMES + EMAILS]
   - Newsletters, cold outreach, automated notices → ⚪
   - Anything about [ADD YOUR #1 PROJECT OR DEAL] → 🔴
3. Give me ONE table: sender · subject · category · one-line why · suggested action.
4. Offer to draft replies for the 🔴 rows. My voice: [ADD 3 WORDS, e.g. warm, brief, decisive].
Never send anything.

  3. Fill in the three blanks

    The three [ADD …] blanks are the only editing you’ll do all day:

    • Your always-red list — the 3–5 people whose email always needs you. Names and addresses.
    • Your #1 project or deal — the thing that jumps every queue right now.
    • Your voice, in 3 words — how your replies should sound. Warm, brief, decisive is a fine start.

    Save the instructions.

  4. Start the daily ritual

    From now on, triage is one sentence, typed inside this project:

    The daily ritual 
    Triage my inbox.
You did it when…

You get one table instead of an inbox.

Why this mattersChat is a conversation; a project is a standing arrangement.
